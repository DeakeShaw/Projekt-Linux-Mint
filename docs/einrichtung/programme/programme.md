# Programme - Übersicht

Auf den neuen Linux-Rechnern sind verschiedene Programme bereits vorinstalliert.
Die meisten davon kennt ihr eventuell schon von Windows, manche sind neu –
hier findet ihr eine kurze Übersicht, wofür ihr sie braucht.

!!! tip "Tipp"
    Diese Seite wird laufend aktualisiert. Schaut hier nach, wenn ihr nicht
    wisst, welches Programm ihr für eine bestimmte Aufgabe nutzen sollt.

??? info "Programm wird vermisst?"
    Nicht jedes Windows-Programm hat eine 1:1-Linux-Alternative – und nicht
    jedes Programm, das es gibt, muss auch bei uns installiert werden. Bevor
    ihr uns schreibt, schaut kurz:

    1. Gibt es das, was ihr braucht, schon in der Liste?
    2. Geht die Aufgabe vielleicht schon mit einem vorhandenen Programm?

    Wenn nicht: Schreibt uns kurz über Wire, **was genau** ihr machen wollt
    (nicht: "ich brauche Programm X", sondern: "ich möchte XY tun"). So
    können wir prüfen, ob es eine passende, sichere Linux-Lösung gibt – das
    kann je nach Programm unterschiedlich lange dauern.

## Häufige Fragen

??? question "Womit öffne ich PDF-Dateien?"
    PDFs öffnen sich automatisch in der vorinstallierten PDF-Anzeige (in diesem Fall ist es vermutlich einer der Browser), wenn ihr
    doppelt darauf klickt. Kein extra Programm nötig.
